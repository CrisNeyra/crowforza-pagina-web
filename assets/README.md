# Assets de CROWFORZA

## Productos y categorías (optimizados)

- `public/assets/products/*.webp` — fotos de catálogo (WebP ~900px)
- `public/assets/categories/*.webp` — imágenes de categorías

Rutas en código: `/assets/products/...` y `/assets/categories/...`

Para regenerar desde URLs remotas:

```powershell
npm run optimize:images
```
